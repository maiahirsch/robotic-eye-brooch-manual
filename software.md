The Interactive Configuration uses software running on the Raspberry Pi 5 and firmware running on the Interactive Controller.

## Raspberry Pi

The Raspberry Pi handles:

- Camera input
- OpenCV
- MediaPipe
- Hand detection
- Tracking logic
- Communication with the controller
