**User & Repair Manual**

## Quick Start

The Robotic Eye Brooch has two main operating configurations:

### Interactive Configuration

Uses the Raspberry Pi 5 and the **Interactive Controller**.

This configuration supports:

- Random eye movement
- Automatic blinking
- Hand tracking
- Interactive left/right eye movement
- Interactive blinking behavior

[How to operate the brooch →](operating.md)

### Extended Wear Configuration

Uses the **Standalone Controller** without the Raspberry Pi.

This configuration supports:

- Random eye movement
- Automatic blinking
- Longer continuous runtime

[Extended Wear setup →](extended-wear.md)

---

## Important Heat Warning

The Raspberry Pi 5 can become hot while running real-time hand tracking, especially while enclosed inside a blazer pocket.

**Do not use the Interactive Configuration continuously for more than approximately 5 minutes.**

For longer periods of wear, use the Extended Wear Configuration.
