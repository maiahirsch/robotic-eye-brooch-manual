# What's Included in the Box

[← Back to Manual](index.md)

The kit includes the assembled Robotic Eye Brooch and several spare or alternate components.

---

## Included Items

- Assembled Robotic Eye Brooch
- Interactive Controller
- Standalone Controller
- External battery pack
- Cable for connecting the Raspberry Pi 5 to the Interactive Controller
- Cable for powering the Standalone Controller from the battery pack
- Second set of Samsung batteries
- Replacement LEDs
- Replacement M2 screws
- Replacement attachment pins
- Wiring diagram

---

## Controller Identification

### Interactive Controller

Use this controller with the Raspberry Pi.

Purpose:

- Random Mode
- Tracking Mode
- LED control
- Push-button control
- Short-duration interactive operation

![Interactive Controller](assets/images/interactive-controller.jpg)

### Standalone Controller

Use this controller without the Raspberry Pi.

Purpose:

- Random movement
- Automatic blinking
- Long-duration operation

![Standalone Controller](assets/images/standalone-controller.jpg)
